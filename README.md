# 안전보건교육 판정·이수관리

근로자별 법정 안전보건교육(정기·채용 시·작업내용 변경 시·특별·건설업 기초, MSDS, 유해성 주지)의 대상 여부와 법적 최소 시간을 판정하고, 이수 진행률·기한·증빙을 관리하는 업무 보조 도구입니다.

## 구성
- `index.html`, `script.js`: 웹 버전. 빌드 도구·외부 라이브러리 없이 GitHub Pages `/(root)`에서 바로 실행됩니다.
- `apps-script/`: 구글 시트 버전. Apps Script 프로젝트에 `script.gs`(= 이 저장소의 `script.js`와 같은 내용), `Sheets.gs`, `Index.html` 세 파일을 넣습니다.

판정 로직과 법령 데이터는 `script.js` 한 곳에 있어 두 버전의 결과가 같습니다.

## 법령 기준
산업안전보건법 시행규칙 현행 2026. 8. 1. 시행(고용노동부령 제477호), 별표 4·5 2025. 5. 30. 개정.

## 데이터 저장
웹 버전의 근로자·이수기록·증빙 파일은 사용하는 브라우저(localStorage, IndexedDB)에만 저장되며 서버로 전송되지 않습니다. 설정 탭에서 백업 파일로 내보내고 가져올 수 있습니다.

## 시연
`시연` 탭에서 가상 사업장((가상) 한빛정밀화학 울산공장, 실존 회사·인물과 무관)의 근로자 10명 데이터를 넣고, 법령 기준 정답표 32건과 자동 대조할 수 있습니다.

> 본 결과는 업무 참고용이며, 최종 판단은 현행 법령 및 관할 지방고용노동관서 해석에 따릅니다.
